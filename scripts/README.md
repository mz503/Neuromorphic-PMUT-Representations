# scripts

Run from the repository root: `python scripts/prepare_data.py`, `python scripts/evaluate.py`, then `python scripts/report.py`. `train.py --family features|reservoir|precision` regenerates fitted models; `train.py --family cnn1d --fold 0 --seed 7` starts a new neural training run. `run_notebooks.py` executes the numbered workflow. See the root README for the complete sequence.
