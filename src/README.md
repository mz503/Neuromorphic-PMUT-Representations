# src

`pmut_models/` contains dataset loading/windowing, CNN1D and exploratory SpikingCNN1D, reservoir dynamics, fixed-point helpers, training, saved-model inference, aggregation and evaluation. `experiments/nb4_feature_extraction.py` and `nb5_feature_ml_baselines.py` expose physical-feature extraction and all six classifiers; `nb14_fixed_point_pmut.py` provides the reduced-precision collector. `reproduction.py`, `validation.py` and `reporting.py` implement the documented workflows.
