# models

The 15 original CNN1D checkpoints and 15 original SpikingCNN1D checkpoints are under `high-glucose_folds_w128/`. Each model has all three folds and five seeds per fold. Their `preprocessing.json` files contain labels and training-only normalisers. `features/` contains six fitted classifiers per fold for both historical full-table and training-fold-only imputation. `reservoir/` contains all five seeds for ESN and both LSM readouts; transparent NPZ exports include reservoir matrices, biases and Ridge coefficients/intercepts/classes. `precision/` contains an independently fitted model for each precision and the float reference. `MODEL_INDEX.csv` identifies every saved model. Regenerated fitted exports are distinguished from original neural checkpoints.
