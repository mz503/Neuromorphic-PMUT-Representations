# configs

`experiments.json` defines the completed benchmark protocol and selected seed sets. `recorded_neural_runs.json` retains actual per-run neural settings and normalisers. `feature_parameters.json` defines all 17 predictors and frequency bands. `reservoir_runs.json` records actual reservoir settings; per-export parameters are also stored next to fitted models. `precision_protocol.json` gives the separate precision split and readout arithmetic.
